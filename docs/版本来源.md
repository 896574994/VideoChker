# 版本来源与开发历程

## 一句话

- **v3.0 之前**的版本，由 **「豆包工作模式」** 制作。
- **v3.0 起**的开发，由 **DeepSeek Harness** 接力完成。

---

## 二、详细说明

这个项目最初是一个**自用的小工具**：用来自查监控录像有没有丢帧、黑屏、静音、
音画不同步等问题，避免"录了但等于没录"。

### 阶段一：豆包工作模式（≤ v2.x）

- 在**豆包（Doubao）的对话式工作模式**里逐步写出来：从一个单文件脚本起步，
  慢慢长成一个多文件的 C# WinForms 程序。
- 这个阶段的产出主要靠"对话 → 贴代码 → 试 → 再改"的循环，
  功能是**一项一项加上去的**。

### 阶段二：DeepSeek Harness 接力（v3.0 起）

- v3.0 起改由 **DeepSeek Harness** 开发。它和前一阶段最大的不同是
  **能直接读写工程、跑编译、跑测试**，所以从这个版本开始加入了工程化的东西：

| 加进来的 | 作用 |
|---|---|
| 自检脚本 | 每次改完自动检查：文档版本号对不对、编码对不对、界面控件有没有重叠、发布包里有没有夹带敏感数据 |
| 冒烟测试 + 验收场景 | 真的启动程序、真的推报警、真的点一遍按钮，把"我以为对"变成"跑过才知道" |
| 交接文档 | 记录**为什么这么做**、踩过哪些坑 —— 代码会说话，但不会解释自己为什么长这样 |
| 健壮性修复 | 例如：随包 ffmpeg 在 Windows 7 上崩、点「停止」时抛异常、覆盖安装继承旧密码锁、安装包上写死的日期 |
| 「导出诊断包」 | 把环境、日志、协议报文收成一个 txt，用户遇到问题只要发一个文件 |

> ★ 以上是**项目方的版本说明**，只陈述事实：哪一段由哪种工作方式完成。
> 它不代表对任何 AI 产品或工作模式的评价。

## 四、开源版改动

为了让这份代码可以公开，开源版做了三处删减（详见 `README.md` **第四节**）：

1. 去掉**主控密码**；
2. 去掉**注册表防绕过镜像**（程序只读写自己目录下的 `data\lock.dat`）；
3. 去掉**作者姓名与联系方式**等个人信息。

代码本身的功能、结构与内部注释风格都保持不变。
