# 视频核对工具（开源版）

一个 Windows 桌面小工具：调用 **FFmpeg**（以及可选的本地 AI 视觉模型）批量检测监控录像和
视频文件的音视频质量，生成 HTML / PDF 检测报告。

- 语言：C# 5（WinForms），**不需要 Visual Studio** —— 用 Windows 自带的 .NET Framework 编译器即可
- 目标框架：.NET Framework 4.x（Windows 7 / 10 / 11 都能跑）
- 许可证：**MIT**（见 `LICENSE`，允许自由使用、修改、再分发、二次创作）

---

## 一、它能做什么

| 能力 | 说明 |
|---|---|
| 本地视频检测 | 音视频完整性、音画同步、音频质量、关键项（黑屏 / 静音 / 花屏等一票否决） |
| 摄像头实时检测 | RTSP 拉流检测：实际帧率与丢帧、码率稳定性、关键帧间隔、画面动态性、时间水印 |
| 网络搜索摄像头 | ONVIF + SSDP 自动发现，自动试出各家不同的 RTSP 取流地址 |
| AI 画面理解（可选） | 接本地 Ollama / 兼容 OpenAI 接口的视觉模型，抽帧分析画面内容 |
| AI 实时巡检 | 三种触发方式：报警主动推图 / ONVIF 事件订阅 / 定时轮询，异常自动告警 |
| 报告 | 一键生成 HTML + PDF 检测报告（摄像头地址会打码） |
| 排障 | 「导出诊断包」把环境、日志、协议报文收成一个 txt，方便发给别人分析 |

## 二、编译与运行

```
1) 装 .NET Framework 4.x（Win10/11 自带；Win7 一般也装了）
2) 双击 build.bat            → 生成 bin\video_checker_gui.exe
3) 准备 ffmpeg（见下）
4) 双击 bin\video_checker_gui.exe
```

### ★ 本仓库**不含 ffmpeg 二进制**

FFmpeg 体积大（约 100 MB），且许可证与本项目不同（GPLv3），所以**没有**放进仓库。
请自行下载 Windows 64 位构建，把 `ffmpeg.exe` 和 `ffprobe.exe` 放到：

```
bin\ffmpeg\bin\ffmpeg.exe
bin\ffmpeg\bin\ffprobe.exe
```

下载地址（任选）：

- https://github.com/BtbN/FFmpeg-Builds/releases （win64-gpl 系列）
- https://ffmpeg.org/download.html

> ### ⚠ Windows 7 用户请注意
> **2024-05-31 之后**的 ffmpeg 构建用到了 Win8/Win10 才有的 API，
> 在 Windows 7 上会**一启动就崩**：退出码 `0xC0000005`，而且标准输出/标准错误**全是空的**。
> 这跟"缺运行库"无关（装 KB2999226 也没用）✗
>
> 请选 **2024-05-31 之前**的构建。实测可用的一份是 **2022-06-29 的 n5.0.1 win64-gpl**。
> 判断方法：命令行跑 `ffmpeg -version`，能正常打印版本号就是好的。

## 四、开源版与原内部版的区别

为了能公开，这个版本刻意去掉了三样东西：

| 去掉的 | 为什么 |
|---|---|
| **主控密码** | 原版有一个硬编码的主控密码，忘记密码时靠它进入 —— 但那同时是一把"万能钥匙"，谁都拿得到，等于锁没锁 |
| **注册表防绕过镜像** | 原版把密码状态同时写进 `HKCU\Software\VideoChecker`，用来防"删文件即解锁"。代价是程序要改注册表，而且密码状态跟着机器走，容易出怪事 |
| **作者姓名 / 联系方式** | 与功能无关的个人信息 |

> ★ **忘了开屏密码怎么办**：删掉程序目录下的 `data\lock.dat` 即可重置 ✓
> 这不是漏洞 —— 能碰到那个文件的人，本来也能直接改程序。
